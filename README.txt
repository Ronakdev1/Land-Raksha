LANDRAKSHA WEBSITE DEMO

1. Open index.html in a browser to preview locally.
2. The site is static HTML/CSS/JavaScript and can be hosted on GitHub Pages.
3. Demo purchase: choose a plan and submit the form. It opens the visitor's email app with a prepared message to support@landraksha.com. The visitor must press Send. No email is sent automatically and no payment is processed.
4. Before public launch, verify plan prices, deliverables, legal/compliance language, contact inbox ownership, and operational availability.
5. To publish on GitHub Pages: create a public repository, upload index.html and the assets folder, then go to Settings > Pages and select Deploy from a branch (main / root).
